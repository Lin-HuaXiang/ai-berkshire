## 第二步：生意本质分析 — 段永平"对的生意"

### 一句话定义

**分众传媒是一门"在城市人必经的封闭空间（电梯）里卖注意力"的生意。**

### 商业模式画布

| 维度 | 分析 |
|------|------|
| **收入模式** | 广告时段/版面销售（非订阅），本质是B2B的注意力批发商 |
| **客户** | 品牌广告主（快消、汽车、互联网、金融等） |
| **核心价值** | 在碎片化媒体时代，提供"不可跳过、不可关闭"的强制性品牌曝光 |
| **成本结构** | 固定成本高（屏幕折旧、物业租金），边际成本低（多播一条广告几乎零成本） |
| **复购驱动** | 广告主持续投放（非一次性），品牌广告需要持续曝光维持心智份额 |

### 5年盈利能力趋势

```
营收(亿): 120.97 → 148.36 → 94.25 → 119.04 → 121.67
          (2020)   (2021)   (2022)   (2023)   (2024)
                    ↑峰值    ↓疫情低谷   ↑恢复    →企稳

净利润(亿): 40.04 → 60.63 → 27.90 → 48.27 → 50.38
            (2020)  (2021)  (2022)  (2023)  (2024)

毛利率: 63.2% → 67.5% → 59.7% → 65.5% → 66.3%
ROE:    26.2% → 33.1% → 14.8% → 28.4% → 29.9%
```

**关键发现**：
1. **强周期性**：营收和利润随宏观经济和广告支出周期大幅波动（2021→2022营收跌36%）
2. **高毛利率稳定**：除2022年极端情况外，毛利率稳定在63-67%，说明定价权强
3. **经营杠杆显著**：营收下降时利润下降更多（2022营收-36%，利润-54%），反之亦然
4. **ROE优秀**：正常年份ROE在26-33%之间，远超资本成本

### 经营杠杆分析

分众的成本结构中，屏幕折旧和物业租金是刚性支出，约占营收的30-35%。这意味着：
- 营收增长10% → 利润可能增长20-25%（正向杠杆）
- 营收下降10% → 利润可能下降20-30%（负向杠杆）

这一特性在2022年得到了充分验证。

### 段永平式追问

> **"这门生意好在哪？如果只能用一句话描述，是什么？"**

好在这门生意**不需要持续大量资本投入就能维持高回报**。毛利率66%、ROE 30%、经营现金流远超净利润——这是一台"印钞机"。段永平说"好的生意就是即使你涨价，客户也离不开你"。分众在2024年提价后，广告主仍在投放，说明品牌广告的不可替代性。

**但另一方面**，这门生意的天花板清晰可见——电梯数量增速放缓，广告主的预算是有限的，分众不能无限提价。

## 第三步：护城河评估 — 巴菲特"经济护城河"

### 五类护城河逐一验证

| 护城河类型 | 验证结果 | 强度 |
|-----------|---------|------|
| **品牌/定价权** | 分众能在不显著损失销量的情况下提价。2024年刊例价上调后，广告主仍持续投放。品牌广告主认可"电梯媒体=分众"的心智定位 | ★★★★ |
| **转换成本** | 中等。广告主从分众转向新潮的转换成本不高（同为电梯媒体），但分众覆盖的写字楼和高端社区点位是新潮难以复制的 | ★★★ |
| **网络效应** | 弱。广告主数量增加不会直接提升对其他广告主的价值。但存在"双边网络效应"：更多点位→更多广告主→更高收入→更多投资→更多点位 | ★★ |
| **规模效应** | 强。300万+点位的规模使分众在屏幕采购、物业谈判、技术研发上有显著成本优势。新潮70-100万点位，成本结构劣势明显 | ★★★★ |
| **技术/专利壁垒** | 弱。电梯屏幕技术门槛低。但数字化能力（程序化投放、AI创意生成、DMP数据平台）正在构建新的技术壁垒 | ★★ |

### 护城河综合评级：★★★★（宽护城河）

**核心护城河来源**：
1. **物理点位垄断**：300万+终端覆盖300+城市，与物业签订的排他性长期合同构成进入壁垒
2. **规模经济**：规模带来的采购、运营、技术成本优势
3. **品牌心智**：在广告主心中，"电梯广告=分众"

### 护城河趋势

**过去5年**：护城河**变宽**。新潮传媒在2018-2019年发起价格战，分众利润大幅下滑。但新潮烧钱数十亿后仍未盈利，2023年被京东收购后转向差异化竞争。价格战结束后，分众利润率快速恢复。

**未来5年**：护城河**稳定偏宽**。电梯保有量仍在增长（中国超1000万台），分众继续扩张点位。数字化能力提升广告精准度和效率。但需警惕：如果短视频广告持续侵蚀品牌广告预算，护城河可能从"广告主离不开"变为"广告主有其他选择"。

### 巴菲特式追问

> **"10年后这条护城河还在吗？什么能摧毁它？"**

10年后电梯还在，人还要坐电梯，物理点位垄断大概率还在。但能摧毁它的有两件事：
1. **广告主彻底转向效果广告**：如果品牌广告作为一个品类消亡（不太可能，但趋势存在）
2. **AR/VR眼镜普及**：人们不再看电梯里的屏幕（远期风险，10年内概率低）

## 第四步：逆向思考与风险清单 — 芒格"反过来想"

### 失败路径分析

| 失败路径 | 概率 | 影响程度 | 说明 |
|----------|------|---------|------|
| 宏观经济长期低迷，广告支出持续萎缩 | 中（20%） | 高 | 2022年已验证：营收-36%，利润-54% |
| 互联网效果广告持续替代品牌广告 | 中高（30%） | 高 | 抖音/快手等提供可量化ROI的广告，广告主预算向线上迁移 |
| 新潮传媒在京东支持下发起新一轮价格战 | 低（10%） | 中 | 京东收购后新潮转向差异化，价格战概率降低 |
| 消费者对电梯广告产生强烈反感，监管介入 | 低中（15%） | 中 | 部分城市已有限制电梯广告音量/时长的讨论 |
| 技术颠覆（AR眼镜、智能电梯替代传统屏幕） | 低（5%） | 高 | 10年内概率极低 |
| 管理层重大失误（盲目多元化/大额收购） | 低（10%） | 中 | 江南春历史上专注主业，但需持续观察 |
| 大客户集中风险（前10大客户收入占比过高） | 中（20%） | 中 | 经济下行时广告主集中度高，单一流失影响大 |

### 历史类比

| 历史公司 | 类比点 | 结局 |
|----------|--------|------|
| **Clear Channel（美国户外广告巨头）** | 户外广告龙头，高杠杆扩张 | 2008年债务危机后衰落，拆分出售 |
| **黄页广告公司（Yellow Pages）** | 本地广告垄断者 | 被互联网广告彻底颠覆 |
| **央视广告** | 中国最大品牌广告平台 | 影响力持续下降，但仍有价值 |

**分众更像央视**：不会被彻底颠覆，但份额会被蚕食。不像黄页那样面临完全替代。

### 偏误自查

- **叙事偏差**：分众的"电梯=必经=强制观看"叙事很有吸引力，但需警惕——广告主最终看的是ROI，不是"强制观看"
- **锚定效应**：2021年营收159.79亿的高点不应作为"正常水平"的锚点
- **幸存者偏差**：只看到了成功的电梯媒体公司，忽略了失败的

### 空方核心论点

1. **增长天花板**：梯媒市场总量~250-300亿，分众已占60-70%，增长空间有限
2. **高分红=无增长**：分红率>70%说明管理层找不到好的再投资机会
3. **周期性风险**：宏观经济下行时利润大幅下滑（2022年已验证）
4. **互联网替代**：效果广告的精准度和可衡量性远超品牌广告，长期趋势不可逆
5. **估值不便宜**：PE 20x对于一个增长5%的公司来说偏高

### 芒格式追问

> **"我最可能在哪里犯错？聪明人为什么不买/做空这家公司？"**

最可能犯错的地方：**高估了品牌广告的持久价值**。如果广告主在未来5-10年全面转向效果广告（按CPC/CPA付费），分众的"品牌曝光"模式可能被边缘化。聪明人不买的原因可能是：看到了这个长期趋势，认为分众是"价值陷阱"——高分红但无增长。

**但另一方面**，品牌广告并未消亡——可口可乐、宝洁、农夫山泉仍在大量投放品牌广告。品牌建设和效果广告是互补而非替代关系。
