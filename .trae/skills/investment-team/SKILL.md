# 投研团队：四大师分析框架

对 $ARGUMENTS 进行团队化投资研究分析。本 Skill 采用单 Agent 顺序执行五阶段分析，依次完成商业模式、财务估值、行业竞争、风险管理四大维度，最后汇总输出综合投资研判报告。

## 输出可读性规则：缩写中文括注

- 报告、表格、标题和结论里出现英文或财务缩写时，必须在旁边用小括号写中文含义，尤其是首次出现和表格标题。
- 重点包括但不限于：FY（财年）、FCF（自由现金流）、OCF（经营现金流）、PE（市盈率）、PB（市净率）、PS（市销率）、EV（企业价值）、EPS（每股收益）、ROE（净资产收益率）、ROIC（投入资本回报率）、ROI（投资回报率）、CAGR（复合年增长率）、CapEx（资本开支）、SBC（股权激励费用）、GAAP（美国通用会计准则）、Non-GAAP（非美国通用会计准则）、EBITDA（息税折旧摊销前利润）、EBIT（息税前利润）、GMV（商品交易总额）、AUM（资产管理规模）、LTV（用户生命周期价值）、CAC（获客成本）。
- 示例：FY2025（2025 财年）、FCF（自由现金流）、PE（市盈率）、ROE（净资产收益率）。
- 同一缩写在同一段落内可不重复解释，但跨章节、表格表头、图表标题再次出现时仍要补中文括注，保证单独截取也能读懂。

## 执行流程

### 第一阶段：展示分析框架与AI研究偏见评估

向用户展示以下分析结构，确认后开始执行：

| 阶段 | 角色/视角 | 职责 | 分析框架 |
|------|----------|------|----------|
| 第一阶段 | Team Lead（你自己） | 统筹协调、汇总研判、输出最终报告 | 四大师综合框架 |
| 第二阶段 | 段永平视角 | 商业模式 & 护城河分析 | 段永平"好生意"标准 |
| 第三阶段 | 巴菲特视角 | 财务报表 & 估值分析 | 巴菲特价值投资框架 |
| 第四阶段 | 芒格视角 | 行业格局 & 竞争态势 | 芒格逆向思考框架 |
| 第五阶段 | 李录视角 | 风险评估 & 管理层研判 | 李录文明演进框架 |

#### AI研究偏见评估（必须执行）

在研究开始前，先评估该公司的"AI可研究性"：

**信息丰富度评级**（决定研究策略）：

| 等级 | 特征 | 研究策略调整 |
|------|------|------------|
| A级（信息充裕） | 上市多年、券商覆盖广 | 研究重点放在**反面检验**和**非共识视角**，避免输出与市场一致的"正确的废话" |
| B级（信息适中） | 上市不久、覆盖有限 | 每个推算数据必须标注置信度，汇总时标注"数据充分度" |
| C级（信息稀缺） | 冷门/新上市/新兴市场 | 转为"第一性原理模式"：不追求报告完整性，聚焦商业本质的几个核心问题 |

**C级公司的第一性原理研究法**：
当公开资料不足时，聚焦以下底层问题：
1. 客户是谁？为什么付钱？有没有替代选择？
2. 复购靠什么驱动？是习惯、锁定、还是持续创造新价值？
3. 竞争对手拿100亿能复制这门生意吗？
4. 管理层做过什么关键决策？这些决策反映了什么判断力和价值观？

**关键提醒**：资料多不等于确定性高，资料少不等于确定性低。AI能输出的置信度不等于投资的真实确定性。确定性来自商业模式本身，不来自资料数量。

将评级结果标注在最终报告的"AI研究局限性声明"中。

### 第二阶段：商业模式分析（段永平视角）

对指定公司从段永平投资视角进行商业模式深度分析。

**分析方法**：
- 使用 WebSearch 搜索最新公开信息（财报、行业报告、新闻、管理层访谈）
- 使用 WebFetch 获取关键文章全文
- 财务数据必须来自两个独立来源，按 `skills/financial-data.md` 规范执行（美股：macrotrends+stockanalysis；港股：aastocks+macrotrends；A股：东方财富+巨潮资讯），两源误差>1%须标记

**分析要点**：

1. **商业模式本质**：核心生意定义、收入结构拆解（近3年分部收入、增速、毛利率）
2. **平台/产品飞轮效应**：飞轮如何运转，各环节驱动关系
3. **护城河分析**：品牌/转换成本/网络效应/规模效应/技术壁垒，逐一验证并提供具体证据
4. **用户/客户价值**：为各方创造了什么独特价值，替代方案的代价有多高
5. **业务矩阵与协同效应**：各业务线之间的关系和交叉导流
6. **段永平"好生意"标准评估**：差异化、定价权、可持续竞争优势
   - 过去3年是否有提价历史？提价后用户流失情况？
   - 这门生意"好"在哪？如果用一句话描述，是什么？
   - 如果股市明天关闭5年，你愿意持有吗？

**输出**：商业模式分析报告，包含护城河评分表和各维度结论。

### 第三阶段：财务与估值分析（巴菲特视角）

对指定公司从巴菲特投资视角进行财务与估值分析。

**分析方法**：
- 使用 WebSearch 搜索最新财务数据（年报、季报、券商研报）
- **所有涉及计算的数据必须通过 Python 工具验算，禁止心算**

**分析要点**：

1. **近3-5年财务趋势**：营收、净利润、经营利润趋势（表格+图表分析）
2. **盈利能力指标**：ROE（净资产收益率）、ROA（总资产收益率）、毛利率、经营利润率，与同行对比
3. **现金流分析**：经营性现金流、自由现金流、资本开支趋势，FCF/净利润比值
4. **资产负债表健康度**：现金储备、有息负债率、流动性比率、净现金/净负债
5. **估值分析**：PE（市盈率）/PS（市销率）/PB（市净率）/EV（企业价值）等，与历史及同业对比
6. **安全边际评估**：内在价值 vs 当前股价

**金融严谨性验证（必须使用Bash调用工具）**：

市值验算：
```bash
python3 tools/financial_rigor.py verify-market-cap --price {价格} --shares {股本} --reported {报告市值} --currency {币种}
```

估值验算：
```bash
python3 tools/financial_rigor.py verify-valuation --price {价格} --eps {EPS} --bvps {每股净资产}
```

关键数据交叉验证：
```bash
python3 tools/financial_rigor.py cross-validate --field {字段} --values '{JSON}' --unit {单位}
```

三情景估值：
```bash
python3 tools/financial_rigor.py three-scenario --price {价格} --eps {EPS} --shares {股本亿} --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE} --years 3 --currency {币种}
```

将工具输出结果直接嵌入报告中作为验证记录。

**输出**：财务估值分析报告，包含完整的估值表格和工具验证记录。

### 第四阶段：行业与竞争分析（芒格视角）

对指定公司所在行业从芒格投资视角进行竞争态势分析。

**分析方法**：
- 使用 WebSearch 搜索行业数据、竞争动态、政策变化（中英文关键词）
- 使用 WebFetch 获取关键行业报告全文

**分析要点**：

1. **行业规模与增长**：市场规模、增速、渗透率、所处阶段（萌芽/成长/成熟/衰退）
2. **竞争格局**：主要对手市场份额、竞争策略对比、份额变化趋势
3. **核心竞争者威胁评估**：逐个分析主要竞争对手的战略意图和资源投入
4. **各细分赛道格局**：公司在各细分市场的位置
5. **行业趋势**：技术变革、政策影响、新进入者威胁
6. **产业链分析**：上中下游价值分配，公司在价值链中的位置
7. **芒格式逆向思考**：
   - 列出"这家公司可能失败的所有路径"（路径/概率/影响程度）
   - 历史类比：找到历史上处于相似位置的公司，结局如何？
   - 聪明人为什么不买/做空这家公司？
   - 我最可能在哪里犯错？

**输出**：行业竞争分析报告，包含波特五力评分表、竞争者对比表和失败路径清单。

### 第五阶段：风险与管理层评估（李录视角）

对指定公司从李录投资视角进行风险与管理层评估。

**分析方法**：
- 使用 WebSearch 搜索监管动态、管理层言论、治理信息
- 关注困难时期管理层的行为模式

**分析要点**：

1. **管理层评估**：CEO能力圈、诚信度、战略眼光、资本配置能力、历史决策质量
2. **监管风险**：当前及潜在监管影响，政策演变方向
3. **竞争风险**：各竞争对手威胁程度评估，被颠覆的可能性
4. **业务风险**：新业务亏损、扩张不确定性、客户/供应商集中度
5. **宏观风险**：经济周期、行业周期影响
6. **治理结构**：股权结构、关联交易、股东回报政策、AB股/VIE风险
7. **长期确定性**：10年后公司会怎样？什么可能颠覆其商业模式？
8. **李录式追问**：站在20年后回看，这家公司是"这个时代的标准石油"还是"昙花一现的3Com"？

**输出**：风险评估报告，包含风险矩阵、管理层评分和长期确定性判断。

### 第八阶段：数据抽检（准出流程）

报告写入文件后，**必须**执行数据抽检：

**Step 1 — 提取抽检清单（15%随机抽样）：**
```bash
python3 tools/report_audit.py extract --report <报告文件路径>
```

**Step 2 — 取数核验：**
对清单中每个数据点，按 `skills/financial-data.md` 规范从可靠信源取数，填入 fetched_value / fetched_source / fetched_value2 / fetched_source2。

**Step 3 — 输出判决：**
```bash
python3 tools/report_audit.py verdict --results '<填好的JSON>' --report <报告文件名>
```

- **【准出】**：所有抽检点偏差 ≤ 1% → 报告可发布
- **【打回】**：任意点偏差 > 1% → 修正对应数据后重新抽检，直到准出

## 核心原则（最高优先级）

1. **客观、客观、客观**——所有分析必须基于事实和数据，严禁主观臆断
2. **严格区分"事实"与"观点"**——事实用数据支撑，观点必须明确标注为"观点"或"推测"
3. **不预设立场**——不预设看多或看空，先摆数据、再推逻辑、最后得结论。结论必须从数据中自然推出
4. **禁止主观表述**——禁用"我认为"、"我觉得"、"显然"等，改用"数据显示"、"证据表明"、"根据XX来源"
5. **呈现正反两面**——每个核心判断都必须附带反面论据（"但另一方面..."），让读者自己权衡
6. **对不确定诚实**——不确定或数据不足时，直接说"不确定"或"数据不足"，不用推测填充确定性
7. **结论要明确**——不回避给出买入/观望/回避建议和具体价格区间
8. **所有分析必须有数据支撑**——附数据来源
9. **反偏见意识**——汇总时必须评估：各阶段分析是否受限于资料充裕度？是否与市场共识过度趋同？最终报告需包含"信息丰富度评级"和"AI研究局限性声明"
10. **信息稀缺时的诚实原则**——宁可在报告中留白标注"数据不足"，也不要用推测填满框架伪装确定性
11. **五位大师语录穿插**——在分析中自然穿插巴菲特、芒格、段永平、李录的语录点评，但不堆砌
