# 公司新闻脉搏：快速归因侦察

对 $ARGUMENTS 指定的公司和事件进行快速侦察与归因分析。

## 输出可读性规则：缩写中文括注

- 报告、表格、标题和结论里出现英文或财务缩写时，必须在旁边用小括号写中文含义，尤其是首次出现和表格标题。
- 重点包括但不限于：FY（财年）、FCF（自由现金流）、OCF（经营现金流）、PE（市盈率）、PB（市净率）、PS（市销率）、EV（企业价值）、EPS（每股收益）、ROE（净资产收益率）、ROIC（投入资本回报率）、ROI（投资回报率）、CAGR（复合年增长率）、CapEx（资本开支）、SBC（股权激励费用）、GAAP（美国通用会计准则）、Non-GAAP（非美国通用会计准则）、EBITDA（息税折旧摊销前利润）、EBIT（息税前利润）、GMV（商品交易总额）、AUM（资产管理规模）、LTV（用户生命周期价值）、CAC（获客成本）。
- 示例：FY2025（2025 财年）、FCF（自由现金流）、PE（市盈率）、ROE（净资产收益率）。
- 同一缩写在同一段落内可不重复解释，但跨章节、表格表头、图表标题再次出现时仍要补中文括注，保证单独截取也能读懂。

## 核心原则

- **快胜过全** —— 10-15分钟内给出可用的归因结论，不要追求穷尽所有信息
- **归因优先于罗列** —— 不是新闻摘要，而是判断"哪个事件是真正的驱动因素"
- **诚实面对"不明"** —— 如果真因无法确定，就说"真因不明，以下是候选假设"
- **区分催化剂和巧合** —— 同日发生的事件不一定有因果关系，需要说明逻辑链

## 第一步：确认参数与场景

从用户输入中提取或询问：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 公司名 | 必填 | 目标公司名称 |
| TICKER | 必填 | 目标公司代码 |
| 时间窗口 | 14天 | 搜索从今天往回多久的事件 |
| 股价异动 | 自动检测 | 用户可指定"跌5%"或"涨8%" |
| 关注侧重 | 全面 | 用户可指定关注特定维度 |

如果用户只提供了部分参数，主动补齐（WebSearch获取）或询问。

## 第二步：信息可得性分级

在开始侦察前，快速评估信息的可得性：

| 等级 | 特征 | 应对策略 |
|------|------|---------|
| A级（信息充裕） | 大型上市公司、券商覆盖广、中英文新闻多 | 重点做归因判断，不要罗列所有新闻 |
| B级（信息适中） | 中型公司、主要市场上市、有基本覆盖 | 在归因的同时标注"信息充分度" |
| C级（信息稀缺） | 冷门公司、新兴市场、非英语为主 | 诚实标注"信息受限"，聚焦可获取的信息 |

## 第三步：四维侦察（按顺序执行）

### 维度1：公司事件

**搜索策略**：
- 使用 WebSearch 搜索："{公司名} {TICKER} announcement filing news"
- 使用 WebFetch 获取关键公告全文（如港交所披露易、SEC EDGAR）

**检查清单**：

| 子维度 | 具体检查项 | 搜索关键词示例 |
|--------|-----------|--------------|
| 公告/披露 | 业绩预告、重大合同、资产重组、停复牌 | "{TICKER}公告" |
| 财报相关 | 季报/年报发布、业绩指引调整、会计变更 | "{TICKER} earnings guidance" |
| 管理层 | 高管变动、增减持、股权激励 | "{TICKER} management change" |
| 业务动态 | 新产品发布、客户突破、产能扩张、裁员 | "{TICKER} product launch" |
| 资本运作 | 增发/配股、回购、分红、并购 | "{TICKER} buyback acquisition" |
| 法律/合规 | 诉讼、调查、处罚、监管问询 | "{TICKER} lawsuit investigation" |

对每个发现的事件，标注：
- **日期**：何时发生/披露
- **来源**：信息出处
- **相关性**：高（直接影响公司基本面）/ 中（有间接影响）/ 低（可能相关或噪音）
- **方向**：利好 / 利空 / 中性 / 不确定

### 维度2：监管与政策

**搜索策略**：
- 使用 WebSearch 搜索行业+政策关键词（使用中英文）

**检查清单**：

| 子维度 | 具体检查项 |
|--------|-----------|
| 行业监管 | 行业新规、监管收紧/放松、准入政策变化 |
| 跨境政策 | 关税、制裁清单、实体清单、出口管制、投资审查 |
| 反垄断 | 反垄断调查、并购审查、不正当竞争处罚 |
| 特殊行业政策 | 如：游戏版号、医疗集采、教培监管、金融监管、数据安全 |

对每个政策事件，标注**直接影响度**：
- **直接命中**：政策明确针对该公司或其核心业务
- **行业波及**：政策针对行业，该公司是行业内重要参与者
- **间接关联**：政策可能通过产业链/市场情绪传导影响

### 维度3：行业与竞争对手

**搜索策略**：
- 使用 WebSearch 搜索：竞争对手名+相关事件
- 搜索产业链上下游关键节点的变化

**检查清单**：

| 子维度 | 具体检查项 |
|--------|-----------|
| 核心对手动态 | 3-5个主要竞争对手是否有重大公告/业绩/产品发布 |
| 产业链上下游 | 上游供应商/下游客户是否有重大变化 |
| 行业景气度 | 行业数据（出货量/价格/开工率等）是否出现拐点 |
| 替代品威胁 | 是否有颠覆性替代品/新进入者引发市场关注 |

**关键判断**：
- 是**公司个体事件**（只有这家公司在跌/涨）还是**行业Beta**（整个行业都在跌/涨）？
- 如果是行业Beta，竞争对手的跌幅/涨幅是否与目标公司一致？

### 维度4：市场情绪

**搜索策略**：
- 使用 WebSearch 搜索券商研报、机构观点、社交媒体讨论
- 使用 WebFetch 获取关键研报摘要

**检查清单**：

| 子维度 | 具体检查项 |
|--------|-----------|
| 卖方评级 | 近期是否有评级上调/下调？目标价调整？ |
| 机构持仓 | 是否有知名机构大幅增减持的消息？ |
| 做空数据 | 做空比例是否异常？是否有做空报告发布？ |
| 大V/意见领袖 | 是否有知名投资者/KOL发表相关言论？ |
| 市场传言 | 是否有未经证实的传言在传播？（需标注"未经证实"） |
| 技术面 | 是否跌破/突破关键技术位？（辅助判断，不作为归因主证据） |

**关键判断**：
- 异动是**基本面驱动**还是**情绪驱动**？
  - 基本面驱动：有明确的公司/行业基本面事件，且逻辑链清晰
  - 情绪驱动：无明显基本面事件，或事件与股价幅度不匹配，更多是市场情绪/资金面变化

## 第四步：综合归因报告

### 一句话归因

> 例："腾讯今日跌5.2%，直接触发因素是XXX，但更深层的原因是YYY"

### 完整事件时间线

按时间顺序排列所有发现的相关事件（近14天），标注权重：

| 日期 | 事件 | 来源 | 维度 | 权重 | 方向 |
|------|------|------|------|------|------|
| | | | 公司/监管/行业/情绪 | 🔴高/🟡中/⚪低 | ↑↓→？ |

### 异动归因总表

| 归因因子 | 解释力（%） | 类型 | 逻辑链 | 置信度 |
|---------|-----------|------|--------|--------|
| 因子1 | 50% | 基本面 | X导致Y导致Z | 高 |
| 因子2 | 30% | 情绪 | A引发B情绪 | 中 |
| 因子3 | 15% | 行业Beta | 行业整体回调 | 高 |
| 未解释 | 5% | - | - | - |

> 解释力合计应等于100%（含"未解释"部分）。

### 性质判断

| 判断 | 说明 |
|------|------|
| **价值事件** | 事件改变了公司的长期价值/基本面，需要重审投资论文 |
| **情绪波动** | 事件不影响基本面，纯粹是市场情绪/资金面变化 |
| **真因不明** | 无法从公开信息确定异动的真正驱动因素 |
| **混合** | 既有基本面因素（占比X%）也有情绪因素（占比Y%） |

### 行动建议

| 建议 | 条件 | 具体行动 |
|------|------|---------|
| **重审论文** | 性质为"价值事件"或核心假设受冲击 | 运行 thesis-tracker mode B |
| **按兵不动** | 性质为"情绪波动"且论文完整 | 不操作，设置下次检查日期 |
| **深入研究** | 性质为"真因不明" | 在报告中列出待研究问题清单 |
| **操作窗口** | 情绪放大基本面利空，出现超跌机会 | 评估是否加仓（需论文健康） |

### 信息缺口声明

明确说明本次侦查的局限性：
- 是否有无法获取但对归因至关重要的信息？
- 是否有待披露的信息（如即将发布的财报、待公告的审批结果）？
- 是否有语言/地域限制导致信息不完整？

## 第五步：保存报告

将报告写入 `reports/{TICKER}/{TICKER}-news-{YYYYMMDD}.md`（日期格式 YYYYMMDD，TICKER为英文名/股票代码，禁止中文）。

## 注意事项

1. **速度优先**：这个 Skill 的目标是10-15分钟内给出可用的归因，不要陷入无限信息收集
2. **不要做价格预测**：归因是回顾性的，不是预测性的。不要写"明天可能反弹"
3. **区分相关性和因果性**：两件事同时发生不一定是因果关系。如果逻辑链不清，标注"相关性待确认"
4. **标注未经证实的信息**：传言、社交媒体消息、非官方来源必须明确标注
5. **货币单位要明确**：股价、市值等数据必须注明币种
6. 如果信息稀缺（C级），不要强行填满四个维度，诚实报告"信息不足"的部分
