# 投资论文漂移检测：Thesis Drift

对 $ARGUMENTS 指定的两份投资论文或研究报告进行结构化对比，检测论文是否发生了实质性漂移。

## 输出可读性规则：缩写中文括注

- 报告、表格、标题和结论里出现英文或财务缩写时，必须在旁边用小括号写中文含义，尤其是首次出现和表格标题。
- 重点包括但不限于：FY（财年）、FCF（自由现金流）、OCF（经营现金流）、PE（市盈率）、PB（市净率）、PS（市销率）、EV（企业价值）、EPS（每股收益）、ROE（净资产收益率）、ROIC（投入资本回报率）、ROI（投资回报率）、CAGR（复合年增长率）、CapEx（资本开支）、SBC（股权激励费用）、GAAP（美国通用会计准则）、Non-GAAP（非美国通用会计准则）、EBITDA（息税折旧摊销前利润）、EBIT（息税前利润）、GMV（商品交易总额）、AUM（资产管理规模）、LTV（用户生命周期价值）、CAC（获客成本）。
- 示例：FY2025（2025 财年）、FCF（自由现金流）、PE（市盈率）、ROE（净资产收益率）。
- 同一缩写在同一段落内可不重复解释，但跨章节、表格表头、图表标题再次出现时仍要补中文括注，保证单独截取也能读懂。

## 核心原则

- **证据优先于措辞** —— 判断漂移看事实和数据变化，不看"语气变了""措辞不一样"
- **基本面优先于股价** —— 股价涨跌不是论文漂移，生意逻辑变化才是
- **数值必须验算** —— 文中所有估值数字必须用 Python 工具验算，不要轻信二手数字
- **红线单独处理** —— 红线触发 ≠ 论文漂移，但需要独立报告

## 三种模式

### 模式A：指定报告对比

用户指定两份报告文件路径进行对比。

### 模式B：自动快照对比

自动查找 `reports/{TICKER}/` 目录下的历史论文和研究报告，取时间最早和最新的两份进行对比（模式A的方法）。

### 模式C：缺失基线

如果只有一份报告，明确说明不能执行漂移检测，引导用户：
1. 先建立投资论文基线（使用 thesis-tracker skill 的模式A）
2. 或者提供两份已有报告进行对比

## 执行流程（模式A）

### A1：读取两份报告并提取关键结构

使用 Read 工具读取报告A（基线/较早）和报告B（对比/较新）。

从两份报告中分别提取：
- **报告标题**、**日期**、**目标公司**
- **核心结论**：一句话总结（与原文措辞可能不同）
- **关键数据点清单**：营收、净利润、毛利率、PE、市值、增长率等
- **核心假设**：报告中明确或隐含的可验证假设
- **估值锚点**：报告中使用的估值框架和参数
- **风险判断**：报告中列出的主要风险及严重程度判断
- **管理层评价**：对管理层的定性判断
- **护城河判断**：对竞争优势的定性判断

输出"报告结构对比表"：

| 维度 | 报告A（{日期}） | 报告B（{日期}） | 初步差异 |
|------|----------------|----------------|---------|
| 核心结论 | | | |
| 关键数据 | | | |
| 核心假设 | | | |
| 估值锚点 | | | |
| 风险判断 | | | |
| 管理层评价 | | | |
| 护城河判断 | | | |

### A2：证据归一化

**关键**：只比较证据，不比较文风。

归一化规则：
- 同样的数据但不同的表述 → 不算漂移（例："营收100亿" vs "营收超过百亿"）
- 同样的判断但不同的措辞 → 不算漂移（例："护城河很深" vs "竞争优势明显"）
- 新增的事实数据 → 需要判断是"新发现"还是"情况变化"
- 消失的担忧/风险 → 需要判断是"风险消除"还是"选择性忽略"
- 措辞强度变化 → 标注但不直接判定为漂移（例："看好"→"非常看好"这是强度升级，不是漂移）

### A3：数值与估值校验

从两份报告中提取所有可计算的数值，使用 Python 工具验算：

```bash
python3 tools/financial_rigor.py cross-validate --field {字段} --values '{JSON}' --unit {单位}
```

检查是否存在：
- **计算错误**：报告中的数值与实际计算不一致
- **数据过时**：使用的是旧数据而非最新可得数据
- **选择偏误**：是否有"摘樱桃"（只挑有利数据）的倾向

### A4：逐维度判定漂移

对5个维度逐一判定，每个维度的判定结果只能是以下三者之一：

| 判定 | 含义 |
|------|------|
| **Improved（改善）** | 证据表明该维度比之前更好 |
| **Unchanged（未变）** | 可获得的证据没有实质性变化 |
| **Weakened（弱化）** | 证据表明该维度比之前更差 |

#### 维度1：估值锚点

- 对比两份报告中的估值逻辑和参数
- 检查：估值倍数（PE/PB/PS）是否有变化？DCF假设是否有调整？目标价是否变化？
- **判定漂移的关键**：估值变化是因为基本面变化还是纯粹因为股价变动？

#### 维度2：核心假设

- 逐条对比核心假设的验证状态
- 检查：是否有假设被证伪？是否有新假设引入？原有假设是否被修改？
- **判定漂移的关键**：假设的变化是否由新的事实证据驱动？

#### 维度3：红线

- 对比预设/隐含的红线清单
- 检查：是否有红线被新增/修改/删除/触发？
- **判定漂移的关键**：红线的调整是否反映了对风险认知的变化？有没有"移动球门柱"（放宽标准以自洽）？

#### 维度4：管理层

- 对比对管理层的定性判断
- 检查：评价是否有明显升级或降级？是否有新的事例被引用？是否有新的担忧出现？
- **判定漂移的关键**：管理层判断的变化是由新行为驱动，还是由股价表现驱动？（警惕"业绩好=管理层优秀"的循环论证）

#### 维度5：护城河

- 对比对竞争优势的判断
- 检查：护城河的描述是否有本质变化？是否有新的竞争威胁出现？壁垒是在加固还是在侵蚀？
- **判定漂移的关键**：护城河判断变化是否有具体的竞争事件支撑？

### A5：证据驱动规则

漂移判定必须遵守以下规则：

1. **找不到证据 → 判定 Unchanged**：不能说"因为没有新数据所以可能变差了"，没有证据就是未变
2. **证据来自公开事实 → 可以判定漂移**：财报数据变化、市场份额变化、管理层变动等
3. **证据来自第三方观点 → 降权**：券商研报、媒体评论不能作为唯一证据，需要交叉验证
4. **证据来自股价 → 忽略**：股价涨跌本身不构成漂移证据

## 注意事项

1. 如果两份报告的时间跨度很短（<2周），大部分维度应该是 Unchanged，不要为了"有输出"而强行找漂移
2. "Improved"和"Weakened"都是漂移，不要只关注负面的漂移
3. 措辞强度变化（如"看好"变"非常看好"）标注出来但不算漂移，除非有新的证据支撑
4. 警惕"后见之明偏误"：用现在的知识去批判过去的判断是不公平的，要基于当时的可得信息来判断当时的判断是否合理
5. 如果发现报告A中有明确的计算错误或信息遗漏，在报告中单独标注"基线报告质量问题"
6. 所有文件路径中的公司名使用英文/拼音，禁止中文
